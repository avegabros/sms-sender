📥 Incoming SMS & Reply Integration Guide
Learn how to configure Webhooks and parse incoming SMS reply patterns such as APPROVE 123, YES, YES 123, and VERIFY 4582.

Popular SMS Reply Command Patterns

1. Action + Reference ID
Examples: APPROVE 123, YES 4582, PAY 9921
Contains both the action command and the target Order/Transaction ID.
2. Simple Keyword Reply
Examples: YES, NO, STOP, HELP
Correlated with the sender's phone number against recent pending database records.
3. Verification / OTP Code
Examples: VERIFY 892140, 892140
Direct match against active 2FA or password reset tokens.

Webhook Payload Received from Gateway

When WEBHOOK_URL is set, your server receives an HTTP POST request in this format:

{
  "event": "sms_received",
  "id": "inbox_1723045800_a1b2",
  "sender": "+639171234567",
  "message": "APPROVE 123",
  "timestamp": "2026-08-07T16:12:00+08:00"
}
Node.js Express - Parsing Command & ID Replies ('APPROVE 123', 'YES 4582', 'YES') 
const express = require('express');
const app = express();
app.use(express.json());

// Webhook endpoint to receive incoming SMS replies from sms-sender
app.post('/webhook/sms-received', (req, res) => {
  const { sender, message, timestamp } = req.body;
  console.log(`Received SMS from ${sender}: "${message}"`);

  const text = (message || '').trim().toUpperCase();

  // Pattern 1: Match 'APPROVE 123', 'YES 4582', 'CONFIRM 991'
  const matchWithId = text.match(/^(APPROVE|CONFIRM|YES|PAY)\s+(\d+)$/i);
  if (matchWithId) {
    const action = matchWithId[1]; // e.g. 'APPROVE' or 'YES'
    const orderId = matchWithId[2]; // e.g. '123'
    console.log(`Command: ${action} for Order #${orderId} from ${sender}`);
    
    // Execute business logic: approve transaction #123 in your database
    // approveOrder(orderId, sender);
  } 
  // Pattern 2: Match simple 'YES' or 'NO' (correlated via sender phone number)
  else if (text === 'YES' || text === 'NO') {
    console.log(`Simple reply '${text}' from ${sender}`);
    
    // Look up latest pending transaction for phone number in your DB
    // handleLatestPendingOrder(sender, text === 'YES');
  } 
  // Pattern 3: Fallback for unmatched replies
  else {
    console.log(`General message received: "${message}"`);
  }

  res.status(200).json({ status: 'success' });
});

app.listen(3000, () => console.log('Webhook server running on port 3000'));
